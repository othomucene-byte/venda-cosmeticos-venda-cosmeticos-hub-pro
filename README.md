# Venda Cosméticos - Venda Cosméticos Hub Pro

Sistema moderno e interativo projetado especificamente para: "Crie a app de venda de cosméticos". Layout totalmente responsivo com controles em tempo real.

## 🚀 Tecnologias
- **React 19 + TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Vite & Edge Deploy (Vercel)**
- **E2B Sandbox MicroVM Isolation**

## 📦 Como Executar Localmente
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Compilar para produção
npm run build
```
